趨同決策

  • 向 React 版慣例靠攏：五件套（.vue / use*.ts / stories.ts / __tests__ / index.ts）、BEM class cl-<kebab>__part、token 只用 var(--cl-*)、a11y 語意（role / aria-live）逐字對齊。
  • 保留 Vant 為 app 層依賴，但設計系統元件自畫：Button / Loading / StatusCard 不再包 van-button / van-loading，否則兩邊樣式與 DOM 無法一致，測試也難共用選擇器。
  • Token 單一來源：新增 src/styles/tokens.css（與 React 逐字相同），tailwind.config.js 全部 map 到 var(--cl-*)；舊 RGB 三元組保留為別名不破壞既有 class。
  • GeoStatusCard 降為薄包裝：內部改用新 StatusCard，status→tone 對映（error→danger、loading→info），既有測試意圖保留、選擇器改成 .cl-status-card--danger。
  • 移除 showAction：StationCard 改成「有 actionText 才顯示按鈕」，與 React 一致。
  • 目錄改名：common-app-tab-bar→tab-bar（改吃 items prop，不再硬編碼五個 tab）、common-app-header→app-header；EmptyState / Loading 從平面檔搬進資料夾五件套並改 <script setup lang="ts">。

踩坑記錄
